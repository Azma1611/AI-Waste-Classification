Project Motivation & Context

Municipalities face a massive problem with recycling contamination. A single contaminated item can ruin a complete batch, sending recyclables to landfills.

  • Traditional waste sorting relies on slow, inaccurate human inspection.
  • Sorting rules are confusing, leading to accidental contamination.
  • Landfills generate methane, contributing significantly to climate change.

The Solution

A vision-based deep learning system that instantenously identifies waste categories, guides consumer disposal, quantifies ecological impact, and offers explainable diagnostic visual maps.

Objectives & Technical Goals

  • Automated Classification: Classify image uploads into 6 target categories.
  • High Verification Target: Attain accuracy thresholds of ≥ 90%.
  • Behavioral Interventions: Provide clear "Do's and Don'ts" per material type.
  • Environmental Transparency: Estimate carbon savings ($CO_2$ kg offset) and environmental scoring.
  • Explainable Decisions: Show model activation maps via Grad-CAM to verify focus points.
  • User-Friendly Access: Deploy a dashboard with offline Chatbot integration.

Data Pipeline & Processing

A strict, sequential data preparation pipeline is built in data_pipeline.py to guarantee clean datasets:

  • MD5 Duplicate Scan: Calculates unique hashes for each image file. Replicates are immediately pruned, guaranteeing zero cross-split leakage.
  • Integrity Filtering: Validates image headers, dropping corrupted, blank, or incomplete uploads.
  • Normalization: Resizes all dimensions to $224 \times 224$ pixels and scales intensity values to the range $[0.0, 1.0]$.

Data Augmentation Strategy

To prevent overfitting and handle environmental variance, we perform real-time data augmentation during the training loop:

  • Geometry: Random horizontal and vertical flips.
  • Rotation: Geometric rotations up to $\pm 20^\circ$.
  • Lighting: Random brightness modifications ($0.85$ to $1.15$).
  • Contrast: Relative contrast adjustments.

Leakage Prevention

Augmentations are applied only on-the-fly during the training phase. The validation and test sets remain unaltered, ensuring scientific validation.

Deep Learning Architectures Explored

We benchmark three distinct classification models:

  • Custom CNN (Baseline): 3 Convolutional blocks (Conv2D -> MaxPooling -> BatchNorm -> Dropout). Relies entirely on custom features.
  • MobileNetV2 (Edge Optimization): Uses pre-trained weights on ImageNet. Lightweight depthwise separable convolutions make it suitable for low-power smart recycling bin computers.
  • ResNet50 (Deep Residual Backbone): Features skip connection loops that permit direct gradient flows, avoiding vanishing gradients in deep layer feature extraction.
Model Engineering Slide 8 of 15

Training Setup & Parameters

  • Optimizer: Adam optimization.
  • Learning Rates: $10^{-3}$ for classification head training; scaled down to $10^{-5}$ during backbone fine-tuning.
  • Loss Function: Categorical Crossentropy.
  • Callbacks: Learning rate reduction on loss plateaus and Early Stopping.

Handling Imbalances

Class weights computed dynamically during training to adjust loss gradients for classes with lower image volumes:

Winner Analysis: ResNet50

Why ResNet50 outperformed other architectures:

  • Skip Connections: Solved degradation issues, enabling high-capacity representation.
  • Fine-Tuning: Unfreezing the top 30 layers let the model adjust generic ImageNet edge features to specific waste shapes.
  • Class Balance: Achieved high recall on the minority class (Organic Waste).

Model Save Location

The winning weights are written to model/waste_model.keras for active production deployment in the Streamlit application.

Explainable AI: Grad-CAM

Grad-CAM computes the gradients of the target class score with respect to the last convolutional layer's feature maps:

  • Identifies the key features the neural network focuses on (e.g., bottle neck caps, electronic grids).
  • Builds confidence for integration into civic recycling infrastructures.
  • Helps diagnose classification errors (e.g., background textures).

Features Map Grid

The Streamlit web application dynamically extracts intermediate layer activations, displaying low, mid, and high-level feature extractions.
