## 📌 Project Overview
An AI-powered smart waste classification and recycling recommendation system built for Assignment 3 (B.Tech AI & Data Science).

### Features
- 🧠 MobileNetV2 deep learning model for waste classification
- 📊 EDA dashboard with class distribution and pixel intensity charts
- ♻️ Recycling recommendations with decomposition time and CO₂ savings
- 🔬 Grad-CAM explainability heatmaps
- 🤖 AI Waste Management Chatbot (Gemini API)
- 🌍 Environmental impact scoring

### Waste Categories
`Plastic` | `Paper` | `Glass` | `Metal` | `Organic Waste` | `E-Waste`

## 🚀 Run Locally
```bash
git clone https://github.com/Azma1611/AI-Waste-Classification.git
cd AI-Waste-Classification
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **ML Model**: TensorFlow / Keras (MobileNetV2)
- **Explainability**: Grad-CAM
- **Chatbot**: Google Gemini API
- **Visualization**: Matplotlib, Seaborn
